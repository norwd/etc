# `XDG_BIN_HOME`

This is where machine specific scripts and utilities are installed,
like `/bin` or `/usr/bin`, this is on the `PATH`,
executable files located here can be run as normal commands.

Note: `XDG_BIN_HOME` is non-standard and is configured manually.
