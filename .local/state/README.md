# `XDG_STATE_HOME`

This contains state files[^difference-between-state-and-data-files], and is analogous to `/var/lib`.
As these files are specific to the local state on each machine,
I really can't think of a time that these will ever be tracked in version control,
so for the forseeable future these are all just `.gitkeep` files.

[^difference-between-state-and-data-files]: Mainly, this means repl history files and the such.
